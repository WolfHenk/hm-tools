**************************** Anleitung Pakete abwählen *******************************

Bitte komplett lesen, dann loslegen!

Am besten das komplette auf dem GitHub-Repository bereitgestellte Release installieren.

Repository dieses Forks:
https://github.com/WolfHenk/hm-tools


***************** Ein Linux System ist vorhanden *****************

git clone https://github.com/WolfHenk/hm-tools.git

cd hm-tools

In der Datei "generate_img.sh" die Zeile

TOOLS=(mc nano htop bash imagemagick sshpass oathtool iostat)

anpassen. Ein Programm, das nicht in das Paket soll, wird aus dieser Liste entfernt.

Die Auswahl gilt für alle drei Architektur-Bereiche:
- arm      = 32-Bit ARM
- aarch64  = 64-Bit ARM
- x86      = i386/i686/x86_64

Raspberry Pi 5 und Compute Module 5 verwenden unter RaspberryMatic den
aarch64-Bereich.

Danach einfach die "generate_img.sh" ausführen.

Jetzt liegt eine fertige Datei "hm-tools-x.x.x.tar.gz" im Projektverzeichnis.
Diese kann wie jedes andere Addon auf RaspberryMatic installiert werden.

******************************************************************


******************* Kein Linux System zur Hand *******************

Die manuelle Änderung eines fertigen tar.gz-Archivs unter Windows bleibt
grundsätzlich möglich. Empfohlen wird jedoch, das Paket unter Linux mit
"generate_img.sh" neu zu erzeugen, damit die Auswahl für alle Architekturen
konsistent bleibt.

Unter
-> Einstellungen
               -> Systemsteuerung
                                 -> Zusatzsoftware

wird im rechten Bereich von HM-Tools angezeigt, welche Erweiterungen installiert sind.

Viel Spaß

Ich hafte nicht für Hard- und Softwareschäden, die am PC-System oder
RaspberryMatic-System durch die Verwendung dieses Addons entstehen.
Verwendung des Addons auf eigene Gefahr.
